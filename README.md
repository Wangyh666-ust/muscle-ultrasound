## 阶段成果与未解决问题

- MT使用已获资格的恢复曲线，输出91→112/112；补回21图MAE1.228mm，共同91图MAE1.270→1.280mm。只修MT，不代表FL接口同步修好。
- 输入、支撑资格、目标层选择、肌束方向与远交点放大已分别诊断；保留未通过实验，未将局部好例混作整体升级。
- 仍有正确边界原始响应不足，也有已有片段未使用、正式FL重拟合偏离恢复曲线的问题。
- 本次673份训练标签重建一致；训练原图上下带Dice约0.923/0.910，但外部困难图持续漏认。部分输入改变还会使联合头有线、身份头却认错上下角色。
- 下一阶段优先验证目标层区分、可信困难结构覆盖和输入/身份一致性；连接与FL几何保真继续独立处理。不把增强数量或训练域高Dice当最终测量改善。
